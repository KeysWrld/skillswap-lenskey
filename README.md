# Skill Swap

A simple Skill Swap web application built with HTML, CSS, and JavaScript.

## Unit 9: API Integration

This project connects to a local Skill Swap backend API running at `http://localhost:3000/api`.

### Run the frontend

1. Install Node.js if it is not already installed.
2. From this folder, run `npm install`.
3. Start the backend API on port 3000.
4. Open `index.html` in a browser, or use the VS Code Live Server extension.

### Tests

Run `npm test` to run the utility function tests.

## Features

- View skills returned by the backend API.
- Filter skills by category.
- Add a skill using the form.
- Calculate total costs and find skill matches.
